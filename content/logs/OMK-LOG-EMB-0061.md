## Purpose

To record the routine quality-control checks of each culture incubator under OMK-SOP-EMB-0062: temperature and CO₂ (and O₂ where applicable), verified against an independent reference at the defined frequency. The log demonstrates that the culture environment stayed within tolerance and provides the trend record for the equipment-maintenance programme (OMK-SOP-EMB-0060). All setpoints and tolerances are held in Appendix A (OMK-APP-EMB-A).

## Scope

One log sheet per incubator per period (e.g. per month). Checks are performed at the frequency defined in Appendix A 🔧 (typically daily on working days). Records the independent-reference reading, not only the incubator display.

## Acceptable ranges (→ Appendix A)

| Parameter | Target | Acceptable range / tolerance |
|---|---|---|
| Temperature | 37.0 °C (ESHRE 2015) | ± tolerance per Appendix A 🔧 |
| CO₂ | set to achieve pH 7.2–7.4 (ESHRE 2015) | acceptable %CO₂ ± tolerance per Appendix A 🔧 |
| O₂ (if controlled) | reduced O₂ ~5% (ESHRE 2015) | ± tolerance per Appendix A 🔧 |

> Out-of-tolerance result. If any reading falls outside the Appendix A range, stop using the incubator for new dishes, move/protect in-process material per OMK-SOP-EMB-0062, and raise a deviation (OMK-SOP-EMB-0005, OMK-SOP-EMB-0005). Record the action in the row.

## Completion instructions

1. Record the incubator and reference-instrument identifiers, and confirm the reference instruments are in-calibration.
2. At each check, record both the incubator display value and the independent reference value for temperature and CO₂ (and O₂ where controlled).
3. Mark each parameter in-range or out-of-range against the Appendix A tolerances — do not write a bare number without comparing it to the range.
4. For any out-of-range reading, record the corrective action taken and the deviation reference; do not leave the action field blank.
5. Initial each completed row. The supervising embryologist reviews and signs the sheet at period end.
